### Overview

This repository is a **customized learning version** of Practical 02. It demonstrates Swift arrays, sets, dictionaries, conditional statements, switch/ranges, loops, and a student-performance summary program. Example module codes, fictional student names, contact data, marks, attendance inputs, and temperature test values have been customized.

### Repository Files

| File | Focus |
| --- | --- |
| `Exercise01.swift` | Arrays and module lists |
| `Exercise02.swift` | Sets and module-enrollment comparison |
| `Exercise03.swift` | Dictionaries and a phone book using **fictional** contact numbers |
| `Exercise04.swift` | `if` / `else if` / `else` attendance evaluation and boundary tests |
| `Exercise05.swift` | `switch` ranges and temperature boundary tests |

### Features Demonstrated

- Adding, removing, finding, and sorting collection elements.
- Union, intersection, and difference operations on sets.
- Dictionary lookup with optional binding.
- Attendance classification through conditional branching.
- Temperature descriptions through `switch` ranges.
- Loop filtering and termination with `continue` and `break`.
- Student letter grades, pass/fail counting, class average, and highest/lowest marks.

### Running the Exercises

Use Xcode or a Swift installation to run **each** Swift file separately (their top-level variables are not intended to be compiled into one target):

```bash
swift Exercise01.swift
swift Exercise02.swift
swift Exercise03.swift
swift Exercise04.swift
swift Exercise05.swift
swift Exercise06.swift
swift FinalChallenge.swift
```

Console outputs for this customized version are saved under `output_logs/`. They were produced using the **Swift 6.2.1 CLI on Linux**; they are not screenshots of an Xcode or iOS Simulator session.
